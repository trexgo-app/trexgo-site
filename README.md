# trexgo-site

Лендинг TrexGo — https://trexgo.app

## Что это

Публичный сайт продукта: описание сервиса ЭТрН/ЭПЛ, тарифы, форма заявки, блог, статьи.
Базы данных и авторизации здесь нет — это статика.

Личный кабинет живёт отдельно: репозиторий `trexgo-lk`, адрес `lk.trexgo.app`.

## Как обновляется сайт

Правки идут **только через ветки**. Ручной деплой с ноутбука (`vercel --prod`) не используется.

```
1. Создал ветку под задачу        git switch -c site-new-pricing
2. Поправил, отправил в гит       git push -u origin site-new-pricing
3. Vercel собрал превью           ссылка появится в pull request
4. Посмотрели вдвоём глазами      кидаем ссылку в телеграм
5. Влили в main                   trexgo.app обновился сам
```

В `main` напрямую пушить нельзя — только через pull request.

## Адреса

| Адрес | Что это |
|---|---|
| `trexgo.app` | боевой сайт, ветка `main` |
| `design.trexgo.app` | черновой дизайн, ветка `design`, под паролем |
| превью-ссылки | по одной на каждую ветку, создаются автоматически |

## Если сломалось

Vercel → Deployments → выбрать предыдущую версию → Promote to Production.
Сайт вернётся к рабочему состоянию за минуту.
