# trexgo-site

Лендинг TrexGo — https://trexgo.ru

## Что это

Публичный сайт продукта: описание сервиса ЭТрН/ЭПЛ, тарифы, форма заявки, блог, статьи.
Базы данных и авторизации здесь нет — это статика.

Личный кабинет живёт отдельно: репозиторий [trexgo-lk](https://github.com/trexgo-app/trexgo-lk).

## Как обновляется сайт

Правки идут **только через ветки**. Файлы по FTP руками не заливаются.

```
1. Создал ветку под задачу        git switch -c site-new-pricing
2. Поправил, отправил в гит       git push -u origin site-new-pricing
3. Посмотрели вдвоём глазами      кидаем ссылку в телеграм
4. Влили в main                   trexgo.ru обновился сам
```

Push в `main` запускает выкладку на хостинг — примерно полминуты.

Откатить последний коммит и запушить — выкладка вернёт предыдущее состояние:

```bash
git revert HEAD && git push
```
