# TrexGo — сайт

Публичный статический лендинг https://trexgo.ru. HTML/CSS/JS без фреймворка и сборки.

## Локальный просмотр

```bash
python -m http.server 8000
```

Страницы — в корне, ассеты — в assets/, серверные обработчики — в api/,
выкладка — в ops/ и .github/workflows/. Секреты не хранятся в Git.

## Документация

[Единая документация сайта](https://github.com/vanss13-ops/trexgo-knowledge-base/blob/main/documentation/site/index.md)
находится в приватной базе и требует доступа. Краткие инструкции разработки
остаются здесь; методология — в AGENTS.md/CLAUDE.md и правилах workspace.

Перед публикацией проверить ссылки и изменённую страницу локально.
Поведение и выкладку менять по правилам workspace; подробный runbook хранится
в knowledge. В этот публичный репозиторий внутренние документы не переносить.
