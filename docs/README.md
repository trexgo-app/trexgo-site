# Лендинг TrexGo — состояние проекта

Статический сайт продукта: ЭТрН/ЭПЛ, тарифы, форма заявки, блог.
HTML/CSS/JS без фреймворка и сборки.

## Адреса

| Адрес | Что это |
|---|---|
| `trexgo.ru` | **боевой сайт**, хостинг Макхост |
| `trexgo.app` | старый адрес на Vercel — режется ТСПУ, судьба не решена |
| `lk.trexgo.ru` | личный кабинет, планируется, отдельный репозиторий `trexgo-lk` |

## Как обновляется сайт

```
1. Ветка под задачу      git switch -c site-new-pricing
2. Правки, отправка      git push -u origin site-new-pricing
3. Слили в main          сайт обновился сам за ~30 секунд
```

Push в `main` запускает [.github/workflows/deploy.yml](../.github/workflows/deploy.yml) —
GitHub Actions заливает файлы на хостинг по FTP. Вручную ничего запускать не нужно.

Есть ручной запуск с галкой «холостой прогон»: Actions → Выкладка сайта на хостинг →
Run workflow. Показывает, что изменилось бы, ничего не трогая.

**Репозиторий — источник правды.** Чего в нём нет, то с сервера удаляется.
Правки прямо на хостинге через FTP затрутся при следующей выкладке.

Не заливаются: `.github/`, `CLAUDE.md`, `README.md`, `docs/`, `config-snapshots/`,
`temp/`, служебные файлы.

## Почему уехали с Vercel

ТСПУ режет клиентские домены Vercel: соединение устанавливается, заголовки приходят,
а тело обрывается на ~21 КБ и висит до таймаута. Проверено на посторонних сайтах —
`resend.com`, `cal.com`, `linear.app` ведут себя так же. Собственные домены Vercel
(`vercel.com`, `nextjs.org`) при этом работают.

Смена IP внутри Vercel не помогает — фильтр следует за именем домена, а не за адресом.

На Макхосте та же картинка 1,09 МБ приходит целиком за 0,5 с.

## Текущие решения

| Решение | Дата | Суть |
|---|---|---|
| Переезд на Макхост | 30.07.2026 | Vercel режется ТСПУ |
| Деплой через GitHub Actions по FTP | 30.07.2026 | шифрования хостинг не поддерживает |
| Репозиторий публичный | 29.07.2026 | Vercel Hobby не умел приватные репозитории организации |
| `.htaccess` в синтаксисе Apache 2.2+2.4 | 31.07.2026 | версия сервера неизвестна |
| phpinfo убран из `httpdocs` | 31.07.2026 | отдавал наружу пути, IP, имя пользователя |

## Что настроено в .htaccess

Редирект HTTP → HTTPS, `www` → без `www`, сжатие, кэш картинок на год,
`/favicon.ico` → `favicon.svg`, блокировка файлов, начинающихся с точки
(кроме `/.well-known/` — он нужен для продления сертификата).

## Проверка, что всё работает

```bash
# Страницы (пока DNS не везде доехал — через прямой IP)
curl -s --compressed -m 20 -o /dev/null --resolve "trexgo.ru:443:178.208.83.20" \
  -w "%{http_code} %{size_download}\n" https://trexgo.ru/

# Тяжёлая картинка — главный тест на ТСПУ, должна прийти целиком
curl -s --compressed -m 40 -o /dev/null --resolve "trexgo.ru:443:178.208.83.20" \
  -w "got=%{size_download} time=%{time_total}\n" https://trexgo.ru/Stati_image/5.png

# Статус выкладок
gh run list --limit 5

# Логи сервера
curl -s --ftp-pasv "ftp://ЛОГИН:ПАРОЛЬ@a250227.ftp.mchost.ru/logs/access_log"
```

## Известные проблемы

**Форма заявки ничего не отправляет.** Обработчик в `script.js` прячет форму и
показывает «Заявка принята» — без `fetch`, без `action`. Контакты посетителей теряются.

**Картинки не пережаты** — 7,91 МБ в 15 файлах, самая тяжёлая 2,25 МБ.
На хостинге грузятся быстро, но на мобильном интернете это много. Есть imagick.

**`perevozchiki.html` — сирота:** на неё нет ни одной ссылки с других страниц.
Возможно, это посадочная под рекламу — уточнить.

**Пароли засветились** в переписке в Telegram: FTP и база. Сменить после того,
как всё устоится, новые — в GitHub Secrets.

**FTP без шифрования** — пароль ходит открытым текстом. Запросить SFTP у поддержки.
