Топливный контроль

Сравнивает нормативный и фактический расход. Выявляет слив, заправку не по норме, неэффективный стиль вождения. Алерт — мгновенно.

Оптимизация маршрутов

Определяет точки простоев по GPS-данным из путевых листов. Выявляет системные задержки на погрузке/разгрузке и у конкретных контрагентов.

FAQ

Вопросы об AI-аналитике

Какой минимальный объём данных нужен для начала работы?

Для базовых отчётов достаточно данных за 2–4 недели работы. Чем больше исторических данных, тем точнее модель: для прогнозного модуля рекомендуется минимум 3 месяца. При подключении мы сразу загружаем исторические данные из ваших систем.

Нужно ли менять существующие системы?

Нет. AI-аналитика работает поверх существующих данных: подключается к вашей GPS-системе и базе ЭТрН. Ничего не нужно менять в текущих процессах.

Кто видит данные моей компании?

Данные изолированы на уровне аккаунта. Модели обучаются только на ваших данных — агрегированные показатели отрасли используются лишь для сравнительных бенчмарков и никогда не содержат ваши исходные данные. Полный NDA по запросу.

В каком формате приходят отчёты?

Интерактивный веб-дашборд (обновляется в реальном времени), еженедельный PDF-отчёт на email руководителя, Excel-выгрузка по запросу, push-уведомления в Telegram или Slack при обнаружении аномалий.
